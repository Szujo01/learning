# FastAPI CRUD Todo

Ez egy egyszerű Todo lista API Python és FastAPI használatával.

A program feladatai:

- új teendő létrehozása;
- teendők lekérése;
- teendő módosítása;
- teendő törlése.

Az adatokat SQLite adatbázis tárolja. A `main.py` indítja az alkalmazást, a routerek kezelik az API végpontokat, a modellek és sémák pedig az adatok szerkezetét írják le.

Kezdőként ebből a projektből megtanulható a REST API, a CRUD működés, a FastAPI és az adatbázis alapvető használata. Az API kipróbálható a `/docs` oldalon.
