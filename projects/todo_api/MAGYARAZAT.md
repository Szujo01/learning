# Todo List API

Ez egy komolyabb Todo API Python és FastAPI használatával.

A program tudása:

- új felhasználó regisztrálása;
- bejelentkezés JWT tokennel;
- személyes Todo feladatok létrehozása, lekérése, módosítása és törlése;
- a felhasználók adatainak elkülönítése.

A projekt aszinkron SQLAlchemyt, Pydantic sémákat és jelszóvédelmet használ. A `/docs` oldalon az API végpontjai kipróbálhatók.

Kezdőként ebből megtanulható a felhasználókezelés, a jogosultság, a tokenes hitelesítés és egy nagyobb FastAPI projekt szerkezete.
